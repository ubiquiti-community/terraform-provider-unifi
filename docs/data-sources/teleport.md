# Teleport (Data Source)

Reads the Teleport settings of a site.

## Example Usage

```terraform
# Read the Teleport settings of a site (defaults to the provider's site).
data "unifi_teleport" "this" {}

output "teleport_enabled" {
  description = "Whether Teleport is enabled."
  value       = data.unifi_teleport.this.enabled
}

output "teleport_subnet_cidr" {
  description = "The subnet used for Teleport, or null when none is set."
  value       = data.unifi_teleport.this.subnet_cidr
}
```

## Schema

### Optional

- `site` (String) The name of the site to read the Teleport settings from. Defaults to the provider's configured site.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `enabled` (Boolean) Whether Teleport is enabled.
- `id` (String) The ID of the data source. It is the name of the site.
- `subnet_cidr` (String) The subnet, in CIDR notation, used for Teleport. Null when no subnet is set.

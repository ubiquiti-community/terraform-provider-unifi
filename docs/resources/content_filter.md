# Content Filter (Resource)

`unifi_content_filter` manages a content filter (Settings > Security > Content Filtering): DNS-based blocking of site categories, plus allow and block lists and safe search, for networks or individual clients.

## Example Usage

```terraform
resource "unifi_network" "lan" {
  name    = "LAN"
  purpose = "corporate"
  subnet  = "10.0.0.1/24"
}

# Block ads and malware on the LAN, force safe search on YouTube.
resource "unifi_content_filter" "lan" {
  name        = "LAN filter"
  network_ids = [unifi_network.lan.id]
  categories  = ["ADVERTISEMENT", "MALWARE", "PHISHING"]
  allow_list  = ["example.com"]
  safe_search = ["YOUTUBE"]
}
```

## Schema

### Required

- `name` (String) Name of the filter.

### Optional

- `allow_list` (Set of String) Domains that are always allowed.
- `block_list` (Set of String) Domains that are always blocked.
- `categories` (Set of String) Blocked categories, e.g. `ADVERTISEMENT`, `MALWARE`, `PHISHING`, `GAMBLING`, `ADULT`, or the presets `FAMILY` and `WORK`.
- `client_macs` (Set of String) MAC addresses of the clients the filter applies to.
- `enabled` (Boolean) Whether the filter is active. Defaults to `true`.
- `network_ids` (Set of String) IDs of the networks the filter applies to.
- `safe_search` (Set of String) Search engines forced into safe search: `GOOGLE`, `YOUTUBE`, `BING`.
- `schedule` (Attributes) When the rule is active. Omit for always. (see [below for nested schema](#nestedatt--schedule))
- `site` (String) The name of the site to associate the filter with.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `id` (String) The ID of the content filter.

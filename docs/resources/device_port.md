# Device Port (Resource)

Manages the overrides of one switch port, identified by `device_mac` and `index`, with the same settings as a `port_override` block of `unifi_device`. Use it to manage a port without declaring the whole device, and to import a single port: the import ID is `<device_mac>/<index>` (or `<site>/<device_mac>/<index>`), which a `port_override` block has no equivalent of. An import stores every setting the controller holds for the port, so the first plan shows what the configuration does not declare; applying it clears those settings, as for a `port_override` block.

The controller has no per-port endpoint, so a write reads the device, replaces this port's entry in its `port_overrides` array and writes the device back; the other ports are left as the controller has them. Attributes left unset keep the controller's value. Writers of the same device from one provider process are serialised, so several `unifi_device_port` resources of one switch can be applied in parallel.

Do not declare the same port both here and in a `port_override` block of `unifi_device`: the two write the same controller field, the last write wins and the other resource drifts. Destroying the resource stops managing the port and leaves its current settings in place, like removing a `port_override` block; reset the port to its defaults before destroying it if that is what you want.

## Example Usage

```terraform
# One port of a switch, managed on its own. The other ports of the switch are
# left as the controller has them, and the port can be imported directly with
# "<device_mac>/<index>".
resource "unifi_device_port" "nas" {
  device_mac = "aa:bb:cc:dd:ee:ff"
  index      = 8

  name                  = "nas"
  native_networkconf_id = unifi_network.servers.id
  poe_mode              = "off"
  stp_edge_state        = "enabled"
}
```

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# Import ID is "<device_mac>/<index>", or "<site>/<device_mac>/<index>" for a
# site other than the provider's. The separator is a slash because the MAC
# address itself is colon-separated.
terraform import unifi_device_port.nas aa:bb:cc:dd:ee:ff/8
```

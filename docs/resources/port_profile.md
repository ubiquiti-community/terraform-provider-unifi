# Port Profile (Resource)

`unifi_port_profile` manages a port profile for use on network switches.

## Example Usage

```terraform
variable "vlan_id" {
  default = 10
}

resource "unifi_network" "vlan" {
  name   = "wifi-vlan"
  subnet = "10.0.0.1/24"
  vlan   = var.vlan_id

  dhcp_server = {
    enabled = true
    start   = "10.0.0.6"
    stop    = "10.0.0.254"
  }
}

resource "unifi_port_profile" "poe_disabled" {
  name = "POE Disabled"

  native_networkconf_id = unifi_network.vlan.id
  poe_mode              = "off"
}

# An access port for end devices: STP edge (forwards as soon as the link is up) with BPDU Guard, which shuts the
# port down if a switch is plugged in behind it.
resource "unifi_port_profile" "desk" {
  name = "Desk"

  native_networkconf_id = unifi_network.vlan.id
  forward               = "native"
  tagged_vlan_mgmt      = "block_all"

  stp_port_mode          = true
  stp_edge_state         = "enabled"
  stp_bpdu_guard_enabled = true
  link_debounce = {
    auto  = false
    delay = "500ms"
  }
}

# An AV port: a Pro AV QoS preset, PTP (needs PTP enabled on the switch), and the port as a multicast router port on
# its network (which needs IGMP snooping).
resource "unifi_port_profile" "av" {
  name = "AV"

  native_networkconf_id = unifi_network.vlan.id
  forward               = "native"
  tagged_vlan_mgmt      = "block_all"

  precision_time_protocol_enabled  = true
  multicast_router_mode            = "CUSTOM"
  multicast_router_networkconf_ids = [unifi_network.vlan.id]
  qos_profile = {
    mode = "dante_audio"
  }
}

# Custom QoS: traffic matching each policy is put in an egress queue (required) and can be re-marked.
resource "unifi_port_profile" "voice" {
  name = "Voice"

  native_networkconf_id = unifi_network.vlan.id

  qos_profile = {
    mode = "custom"
    policies = [
      {
        matching = { protocol = "udp", dscp_code = 46 }
        marking  = { queue = 6 }
      },
      {
        matching = { protocol = "tcp", dst_port = 5061 }
        marking  = { queue = 5, dscp_code = 26 }
      },
    ]
  }
}
```

## Schema

### Optional

- `autoneg` (Boolean) Enable link auto negotiation for the port profile. When set to `true` this overrides `speed`. Defaults to `true` for a newly created profile; an existing profile keeps the controller's value.
- `dot1x` (Attributes) 802.1X port authentication settings for the port profile. Taken from the controller when not set. (see [below for nested schema](#nestedatt--dot1x))
- `eee_enabled` (Boolean) Enable Energy Efficient Ethernet (802.3az): the link enters a low-power state when traffic is low. The UI does not offer it together with a Pro AV `qos_profile`. Taken from the controller when not set.
- `egress_rate_limit` (Attributes) Egress rate limiting for the port profile. Computed from the controller when not set; disable with `enabled = false` rather than by removing the block. (see [below for nested schema](#nestedatt--egress_rate_limit))
- `excluded_networkconf_ids` (Set of String) The IDs of networks excluded from the port profile (used when `tagged_vlan_mgmt` is `custom`). Computed from the controller when not set.
- `fec_mode` (String) Forward Error Correction mode. Can be `rs-fec`, `fc-fec`, `default`, or `disabled`.
- `flow_control_enabled` (Boolean) Enable flow control (802.3x pause frames). Taken from the controller when not set.
- `forward` (String) The type forwarding to use for the port profile. Can be `all`, `native`, `customize` or `disabled`. When unset it follows `tagged_vlan_mgmt`, which is what the controller stores for that mode: `all` for `auto`, `native` for `block_all`, `customize` for `custom`. `customize` requires a native network that carries a VLAN id, unless `tagged_vlan_mgmt` is `custom`: otherwise the controller silently stores `all` for a profile whose native network is untagged, which the provider rejects at plan time rather than letting the apply leave the resource tainted.
- `full_duplex` (Boolean) Enable full duplex for the port profile. Taken from the controller when not set.
- `isolation` (Boolean) Enable port isolation for the port profile. Taken from the controller when not set.
- `link_debounce` (Attributes) Link debounce for the port profile: delays link state changes to ignore brief interruptions and reduce link flapping. Higher values can improve stability but may slow failover or recovery. Taken from the controller when not set. (see [below for nested schema](#nestedatt--link_debounce))
- `lldpmed` (Attributes) LLDP-MED settings for the port profile. Taken from the controller when not set. (see [below for nested schema](#nestedatt--lldpmed))
- `multicast_router_mode` (String) Multicast router port mode (the UI's Multicast Router Port, with IGMP snooping): `NONE`, `ALL` (a multicast router port on every network of the port) or `CUSTOM` (on the networks in `multicast_router_networkconf_ids`, each of which needs IGMP snooping; the controller rejects the profile otherwise). Taken from the controller when not set; once set, it cannot be returned to unset, use `NONE`.
- `multicast_router_networkconf_ids` (Set of String) The IDs of networks on which the port is a multicast router port, used when `multicast_router_mode` is `CUSTOM`. Each network needs IGMP snooping.
- `name` (String) The name of the port profile.
- `native_networkconf_id` (String) The ID of network to use as the main (native/untagged) network on the port profile. Assigned by the controller if not set.
- `op_mode` (String) The operation mode for the port profile. Can only be `switch`
- `poe_mode` (String) The POE mode for the port profile. Can be one of `auto`, `passv24`, `passthrough` or `off`.
- `port_keepalive_enabled` (Boolean) Enable port keepalive for the port profile. Taken from the controller when not set.
- `port_security` (Attributes) Port security (MAC allow-list) settings for the port profile. Computed from the controller when not set; disable with `enabled = false` rather than by removing the block. (see [below for nested schema](#nestedatt--port_security))
- `precision_time_protocol_enabled` (Boolean) Enable Precision Time Protocol (PTP) on the port, for AV timing (AES67, SMPTE ST 2110). It needs PTP enabled in the switch's settings, and does not run over aggregated ports. Taken from the controller when not set.
- `priority_queue1_level` (Number) The priority queue 1 level for the port profile. Can be between 0 and 100.
- `priority_queue2_level` (Number) The priority queue 2 level for the port profile. Can be between 0 and 100.
- `priority_queue3_level` (Number) The priority queue 3 level for the port profile. Can be between 0 and 100.
- `priority_queue4_level` (Number) The priority queue 4 level for the port profile. Can be between 0 and 100.
- `qos_profile` (Attributes) QoS profile for the port profile (the UI's Pro AV and custom QoS): a preset `mode` for an AV protocol, or `custom` with your own `policies`. Taken from the controller when not set; `qos_profile = {}` removes it. The UI does not offer Pro AV and EEE together on one port. (see [below for nested schema](#nestedatt--qos_profile))
- `setting_preference` (String) Whether the port profile settings are managed automatically or manually. Can be `auto` or `manual`.
- `site` (String) The name of the site to associate the port profile with.
- `speed` (Number) The link speed to set for the port profile. Can be one of `10`, `100`, `1000`, `2500`, `5000`, `10000`, `20000`, `25000`, `40000`, `50000` or `100000`
- `stable_port_enabled` (Boolean) The controller's `stable_port_enabled` setting. Network 11.0 defines it for port profiles but does not show it in its UI. Taken from the controller when not set.
- `stormctrl` (Attributes) Storm Control settings for the port profile. Computed from the controller when not set; disable a class with `enabled = false` rather than by removing the block. (see [below for nested schema](#nestedatt--stormctrl))
- `stp_bpdu_guard_enabled` (Boolean) Enable BPDU Guard: the switch shuts the port down if it receives STP BPDUs (a switch behind it), and the port stays down until it is re-enabled by hand. For ports facing end devices, typically with `stp_edge_state = "enabled"`; the UI does not offer it on an `stp_uplink` port. Taken from the controller when not set.
- `stp_edge_state` (String) STP edge port mode: `enabled` (the UI's STP Edge: the port forwards as soon as its link comes up and takes no part in STP convergence, for end devices) or `disabled`. Taken from the controller when not set; a profile that never set it uses the switch's Auto STP Edge and reads as null. Once set, the controller only accepts `enabled` or `disabled`: it cannot be returned to Auto STP Edge through the API.
- `stp_port_mode` (Boolean) Enable Spanning Tree Protocol (STP) for the port profile. Computed from the controller when not set.
- `stp_uplink` (Boolean) Mark the port as the preferred STP uplink (the UI's STP Uplink): on a non-root switch, the port STP keeps forwarding when it blocks redundant paths. Taken from the controller when not set.
- `tagged_networkconf_ids` (Set of String) The IDs of networks to tag traffic with for the port profile.
- `tagged_vlan_mgmt` (String) How tagged VLANs are managed on the port. Can be `auto`, `block_all`, or `custom`.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))
- `voice_networkconf_id` (String) The ID of network to use for voice traffic for the port profile.

# Wan Sla (Resource)

`unifi_wan_sla` manages a WAN SLA profile (Network 11: Settings > Profiles > WAN SLA). A profile has one or more verification servers, ICMP or DNS, each with packet loss, latency and jitter thresholds. When enough servers breach their thresholds, the WANs using the profile (`unifi_wan.sla_id`) are considered unusable and taken out of load balancing or failover.

## Example Usage

```terraform
# unifi_wan_sla manages a WAN SLA profile (Network 11: Settings > Profiles > WAN SLA): the check that decides whether
# a WAN is usable. WANs reference it with unifi_wan.sla_id; a WAN whose profile is down is taken out of load balancing
# or failover.
#
# Here a server breaches on packet loss, or on latency and jitter together, and the WAN is unusable when most servers
# breach, so one unreachable target can't take a WAN out.
resource "unifi_wan_sla" "standard" {
  name                = "wan-standard"
  monitor_health_type = "MAJORITY"

  monitors = [
    {
      type              = "ICMP"
      target            = "1.1.1.1"
      interval          = 1
      time_period       = 30
      threshold_policy  = "loss-or-all-others"
      loss_threshold    = 10
      latency_threshold = 150
      jitter_threshold  = 30
    },
    {
      type              = "ICMP"
      target            = "9.9.9.9"
      interval          = 1
      time_period       = 30
      threshold_policy  = "loss-or-all-others"
      loss_threshold    = 10
      latency_threshold = 150
      jitter_threshold  = 30
    },
    {
      type              = "DNS"
      target            = "8.8.8.8"
      domain            = "example.com"
      interval          = 5
      time_period       = 60
      threshold_policy  = "loss-or-all-others"
      loss_threshold    = 10
      latency_threshold = 150
      jitter_threshold  = 30
    },
  ]
}

# Two WANs load balanced 50/50, both judged by the profile.
resource "unifi_wan" "primary" {
  name         = "Internet 1"
  load_balance = { type = "weighted", weight = 50, failover_priority = 1 }
  sla_id       = unifi_wan_sla.standard.id
}

resource "unifi_wan" "secondary" {
  name         = "Internet 2"
  load_balance = { type = "weighted", weight = 50, failover_priority = 2 }
  sla_id       = unifi_wan_sla.standard.id
}
```

## Schema

### Required

- `monitor_health_type` (String) When the profile is considered down: `ALL` (every server breaches), `ANY` (any one), `MAJORITY` (more than half) or `CUSTOM` (`monitor_down_threshold` servers).
- `monitors` (Attributes List) The verification servers. (see [below for nested schema](#nestedatt--monitors))
- `name` (String) The name of the profile.

### Optional

- `monitor_down_threshold` (Number) With `monitor_health_type = "CUSTOM"`: how many servers must breach for the profile to be down.
- `site` (String) The name of the site the profile belongs to.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `id` (String) The ID of the WAN SLA profile.

<a id="nestedatt--monitors"></a>
### Nested Schema for `monitors`

Required:

- `interval` (Number) Seconds between probes (1-3600).
- `target` (String) ICMP: the host name or IPv4 address pinged. DNS: the IPv4 address of the DNS server queried.
- `threshold_policy` (String) Which of the thresholds set must be exceeded for this server to breach: `any`, `all`, `any-two`, `loss-or-all-others`, `latency-or-all-others`, `jitter-or-all-others`, `loss-plus-one`, `latency-plus-one` or `jitter-plus-one` (e.g. `loss-or-all-others` = packet loss, or both latency and jitter).
- `time_period` (Number) Seconds over which probe results are averaged (1-65535). The controller requires it to exceed twice the interval plus the latency threshold in seconds.
- `type` (String) `ICMP` (ping) or `DNS` (a query for `domain`).

Optional:

- `domain` (String) DNS only: the name resolved against `target`.
- `jitter_threshold` (Number) Jitter threshold in milliseconds (3-1500). Unset disables it.
- `latency_threshold` (Number) Latency threshold in milliseconds (5-10000). Unset disables it.
- `loss_threshold` (Number) Packet loss threshold in percent (1-100). Unset disables it.

Read-Only:

- `monitor_id` (Number) The controller's ID for this server.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# WAN SLA profiles can be imported using the profile ID (Network 11 uses UUIDs), or site:id for a non-default site.
terraform import unifi_wan_sla.standard 00000000-0000-4000-8000-000000000002

# For a non-default site, prefix the ID with the site name and a colon.
terraform import unifi_wan_sla.standard default:00000000-0000-4000-8000-000000000002
```
